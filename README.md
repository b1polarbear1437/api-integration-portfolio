# API Integration Portfolio (Python)

This repository contains Python-based examples demonstrating REST API integrations, authentication, error handling, and data processing.

## Tools Used
- Python 3
- requests library
- REST APIs (JSON)

## Examples Included
- GET requests to retrieve data
- POST requests to create resources
- Bearer token authentication
- Basic error handling
- Pagination handling

## How to Run
1. Install dependencies: pip install -r requirements.txt
3. Run any script: python get_users.py


## Notes
Public APIs are used for demonstration purposes. No sensitive credentials are stored in this repository.
